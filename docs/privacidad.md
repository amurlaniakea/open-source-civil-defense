# Privacy Policy

## Our Commitment

OSCD is built on the principle that the privacy of attack victims is paramount. This policy explains how we handle data.

## Principles

1. **No sensitive data in the repository. Ever.**
2. **All case studies are anonymized** before publication.
3. **Consent required.** No case is documented without explicit consent.
4. **Minimal data collection.** We collect only what is necessary.
5. **No data sharing.** We never share report data with third parties.
6. **Right to removal.** Anyone can request data removal at any time.

## What We Collect

### Incident Report Form
- Contact name or alias (required)
- Contact email (required)
- Repository name/URL (optional)
- Package manager (optional)
- Incident description (required)
- Impact assessment (required)
- Evidence links (optional)

### Website/Analytics
- We use no analytics, no cookies, no tracking.

## What We Never Collect

- Passwords or access tokens
- Private encryption keys
- Personal identification numbers
- Payment information
- Browser fingerprints

## Data Retention

| Data Type | Retention Period |
|---|---|
| Active case data | Until resolution + 90 days |
| Anonymized case studies | Indefinitely (public documentation) |
| Form submissions | Deleted after resolution (unless consent given) |
| Email communications | 1 year after case closure |

## Data Location

- Private reports: encrypted email inbox
- Case studies: GitHub repository (public, anonymized)
- No database servers, no cloud storage

## Third Parties

We do not share data with any third parties. When we facilitate reporting to GitHub Security or OpenSSF, we only share the anonymized technical details needed for their processes.

## Your Rights

- **Right to access:** Request a copy of data we hold about you
- **Right to rectification:** Request correction of inaccurate data
- **Right to erasure:** Request deletion of your data
- **Right to withdraw consent:** Revoke consent for case documentation at any time

## Contact

For privacy-related requests, email the project coordinator.
