# Recommended Tools

A curated list of open source security tools for developers and maintainers.

## Supply Chain Security

| Tool | Description | Language |
|------|-------------|----------|
| [Socket](https://socket.dev/) | Detects supply chain attacks in npm packages | Multi |
| [Snyk](https://snyk.io/) | Vulnerability scanner for dependencies | Multi |
| [OpenSSF Scorecard](https://securityscorecards.dev/) | Automated security scoring | Multi |
| [pip-audit](https://pypi.org/project/pip-audit/) | Audit Python packages | Python |
| [cargo-audit](https://rustsec.org/) | Audit Rust dependencies | Rust |

## Code Analysis

| Tool | Description | Language |
|------|-------------|----------|
| [Semgrep](https://semgrep.dev/) | Static analysis for security bugs | Multi |
| [CodeQL](https://codeql.github.com/) | Semantic code analysis | Multi |
| [Bandit](https://bandit.readthedocs.io/) | Security linter for Python | Python |
| [Brakeman](https://brakemanscanner.org/) | Security scanner for Rails | Ruby |

## AI Agent Security

| Tool | Description | Language |
|------|-------------|----------|
| [MCP Core Defense](https://github.com/amurlaniakea/mcp-core-defense) | MCP tool description scanner | Rust/Python |
| [Agent Fixer Stage](https://github.com/amurlaniakea/agent-fixer-stage) | Malicious output detection | Python |

## Account & Access Security

| Tool | Description |
|------|-------------|
