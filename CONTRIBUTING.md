# Contributing to OSCD

Thank you for your interest in contributing to Open Source Civil Defense! This document explains how you can help.

## Ways to Contribute

### 1. Document a Case Study

The most valuable contribution is documenting a resolved security incident. See [casos/](./casos/) for existing examples.

**Requirements:**
- The case must be from a **public source** or have **explicit consent** from the victim
- All sensitive data must be **anonymized**
- Follow the case study template in `.github/ISSUE_TEMPLATE/caso-de-estudio.md`

### 2. Improve Documentation

- Fix typos, improve clarity, add examples
- Translate content to other languages
- Add guides for specific types of attacks

### 3. Add Tools

- Recommend open source security tools
- Write guides on how to use existing tools
- Share scripts that help with incident response

### 4. Become a Guardian

Guardians are trusted community members who help respond to incident reports. To become a Guardian:

1. Demonstrate expertise in security, code audit, or incident response
2. Contribute at least 3 meaningful contributions to the project
3. Be invited by the Coordinator

**Guardians must:**
- Respect the privacy of victims at all times
- Never access repositories without explicit permission
- Follow the Code of Conduct strictly
- Report any potential conflicts of interest

## Pull Request Process

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-contribution`
3. Make your changes
4. Ensure all content is accurate and well-formatted
5. Submit a Pull Request with a clear description

## Content Standards

- All content must be in **English** (other languages welcome as translations)
- Use clear, professional language
- Cite sources for factual claims
- Do not include sensitive information (tokens, passwords, private URLs)
- Follow the existing file structure and formatting

## Reporting Vulnerabilities in OSCD

If you find a security vulnerability in OSCD itself, **do not open a public Issue**. See [SECURITY.md](./SECURITY.md) for responsible disclosure.

## Questions?

Open an Issue using the "Contribution Suggestion" template to propose ideas or ask questions.
