# Security Policy

## Supported Versions

This project is a documentation and community resource. There are no "versions" in the traditional sense. All content is continuously updated on the `main` branch.

## Reporting a Vulnerability

If you discover a security vulnerability in OSCD itself (e.g., exposed credentials, XSS in any associated tools, privacy leak):

**DO NOT open a public GitHub Issue.**

Instead, report privately via email to the project coordinator. Include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Privacy Policy

OSCD handles sensitive information about security incidents. Our privacy principles:

1. **No sensitive data in the repository.** Ever.
2. **All case studies are anonymized** before publication.
3. **Consent required.** No case is documented without explicit consent from the affected party.
4. **Minimal data collection.** The private report form collects only what is necessary.
5. **No data sharing.** We do not share report data with third parties.
6. **Right to removal.** Any person can request removal of their data at any time.

## What We Collect

The private incident report form collects:

- Contact name/alias (required)
- Contact email (required)
- Repository name/URL (optional)
- Package manager (optional)
- Incident description (required)
- Impact assessment (required)
- Evidence links (optional)

## What We Never Collect

- Passwords or access tokens
- Private keys
- Personal identification information
- Payment information

## Data Retention

- Active case data: retained until case is resolved + 90 days
- Anonymized case studies: retained indefinitely as public documentation
- Form submissions: deleted after case resolution unless consent is given for anonymized documentation

## Contact

For security concerns or privacy requests, contact the project coordinator via the private form or email.
